# PI Helper

PI Helper is a Django web application for practicing and memorizing the digits of π.

- Features

* Challenge mode with multiple lives
* Hard Mode with one life and limited digit visibility
* Custom starting and ending digit
* Unlimited mode using all available digits
* Timer and personal best times for specific digit ranges
* User accounts with email verification
* Login using username or email
* User profiles and statistics
* Playing streaks
* Password change with email confirmation
* Achievements

## Technologies

* Python
* Django
* SQLite
* HTML
* CSS
* JavaScript

- Installation

Clone the repository:

git clone <repository-url>
cd PI-Helper

Create and activate a virtual environment:

py -m venv .venv
.venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

Apply migrations:

py -m manage migrate

Start the development server:

py -m manage runserver

Then open the address shown by Django in your browser.
